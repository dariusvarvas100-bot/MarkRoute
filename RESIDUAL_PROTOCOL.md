# Does the terrain starting estimate help when both models have terrain?

**Hypothesis.** Predicting the correction to the terrain-based starting elevation transfers better to geographically distant river floods than learning the absolute elevation or correcting other local starting estimates. All compared learned models get the same terrain and survey information.

Use the same histogram gradient boosting configuration, same four training floods and 18 starting-survey masks. Augment the existing features with the unrounded numeric elevations from the terrain-based starting estimate, inverse-distance interpolation and bounded terrain regression, so the direct model can see each absolute estimate as an input. Give that identical feature matrix to four strategies. The strategies learn the absolute elevation, the correction to inverse-distance interpolation, the correction to bounded terrain regression, or the correction to MarkRoute's terrain-based starting estimate. The frozen release itself is reported separately using its original features and original starting estimate.

Select the strongest alternative on riverine marks in Florence and Michael by MAE before scoring the eight remote floods. The primary group is riverine sites in those eight floods. Use identical test masks, targets and revealed measurements. The alternative fit may use scores from the development floods for selection only. The primary hypothesis requires at least 5% lower MAE than that development-selected alternative and a strictly positive paired 95% interval from resampling floods and 10 km spatial blocks. Report all strategies, all test floods, errors over five feet, and a secondary test with the pooled coastal and riverine marks. The earlier point-model outcomes and the terrain-removal outcomes for these floods were already known. The comparison tests learning formulations in a retrospective replay.

Related research on learning hydrologic model corrections. [Jiang et al., Hydrology and Earth System Sciences](https://hess.copernicus.org/articles/29/3589/2025/)
