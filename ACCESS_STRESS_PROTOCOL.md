# Candidate-access stress test

Reuse the released four-flood point estimator, crew-study event panels, 12 survey masks (7162–7173), original initial marks, candidate and scoring pools, and original successful-visit budgets. Score exactly the same held-out records. For each nonempty candidate pool, define the number blocked as the closest integer to 30% of that pool, with halves rounded up. No blocked mark enters any revised survey. Existing measurements and scoring locations stay unchanged.

The scattered scenario blocks a uniform random sample of candidate indices. The clustered scenario picks a uniform random candidate as the center and blocks it and its closest other candidate marks by straight-line distance. Break ties in original candidate order. Derive each closure random generator from SHA256 of the event ID, environment, mask number, and scenario name. This prevents access generation from using survey heights or sharing the random policy's ordering. These scenarios represent synthetic loss of candidate access. Physical routes, actual roads, site ownership, and probability or duration of access loss are outside the data.

Give every policy the same available candidates and original visit count. Replan with unchanged nearest, farthest-first and terrain coverage objectives. The random control restricts its original random ordering to permitted candidates. Recompute terrain similarity over eligible candidates and scoring locations. Assert eligibility is known before extra elevations are read, ineligible or scoring elevations never enter feature construction, and requested successful visit counts are met for each policy. Preserve the no-extra prediction as an invariant across access conditions. The primary comparisons are pooled MAE and errors over five feet across the original 13-flood crew-study sample. Report each event, 95% paired intervals conditional on the observed event set (10 km blocks, all repeat masks kept), deterioration relative to unrestricted access, and a descriptive steep riverine subset (raster relief ≥35 ft). Report all results. Apply the same rules without tuning to the two prepared Arkansas and New Hampshire panels as a small transfer check. For illustration only, show the preexisting June 2022 Montana case, seed 7162.

Run `python access_stress.py` from a flat MarkRoute package containing the crew-study replay, data, and locks. The script checks the prior published input hashes before running and re-creates `access_stress_lock.json` and `access_stress_results.json` offline from the bundled prepared tables.
