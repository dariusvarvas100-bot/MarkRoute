# Same-budget field visit replay

Compare a fixed terrain-coverage batch with nearest-to-an-initial-survey, farthest-first, and random batches. Use the previous survey-decision experiment's 12 masks and exact split of known measurements, eligible visits, and permanently scored marks within each flood and environment. Each visit policy receives the same starting observations and makes exactly the same number of extra visits, approximately 10 percent of the full environment's marked locations (the existing code rounds by cohort and caps to the candidate pool). Each batch is fixed before observing any new elevation. All methods retain the same released four-training-event MarkRoute estimator and predict the same permanently withheld rows. A no-extra-survey reference measures the value of the measurement round, separately from equal-budget comparisons.

Use exactly the terrain coverage, farthest-first and random rules from the previous study. Terrain coverage greedily improves nearest-available measurement similarity at scoring locations using the existing Matérn kernel, 0.75 horizontal-factor setting, 45 ft terrain scaling and named-waterbody agreement. This geometry rule was selected as the strongest simple same-budget comparator in the earlier development replay and is not retuned here. Nearest chooses the shortest straight-line distance to any existing anchor, computed once per candidate before ranking, with stable order for ties. No scoring or candidate elevations are accessible during ranking.

The primary retrospective replay covers the original 13 benchmark floods, already known for the point-model task. Report paired absolute error, >5-ft errors, event-specific results, and paired intervals independently resampling 10 km spatial blocks within each fixed event. All repeatedly scored rows from a block stay together. Report riverine sites with raster relief of at least 35 ft as a predeclared descriptive subgroup, keeping all corresponding within-event anchors. Outcome-free plan distance and travel cost are different quantities. The replay compares interventions on the set of observed measurements while holding the measured flood and score locations fixed. Crews' travel paths, costs, access, achievable visits, flood-time decisions and survey measurement noise are not measured.

As a separate prospective-to-the-policy evaluation, apply the same policy and locked checks to the official June 2010 Little Missouri River, Arkansas and October 2005 Cold River, New Hampshire panels. These were prepared from primary field reports. Admit each only if the event is absent from all previous MarkRoute panels, site/location uniqueness and source hashes validate, vertical datum is NAVD88 in feet, and terrain is available. Record closest distances and coordinates shared with prior sites. No rule selection uses either event. Both are limited-area floods; report flood-specific performance and the number of independently resampled spatial blocks rather than extrapolating their pooled interval to new floods.

From a flat package with the bundled prepared panels and their source locks, use `python crew_replay.py` to reproduce both cohorts and the worked Montana example. This uses the SHA256-pinned prepared field tables. To verify the source PDFs against the same locks, save the reports as `AR_LittleMissouri_2010.pdf` and `NH_ColdRiver_2005.pdf` next to the prepared panels and run `python crew_replay.py --verify-reports`. The study does not download reports or terrain during reproduction.
